Clothesline

把一张张截图，挂在屏幕顶上的一根晾衣绳上。
要用的时候推一下鼠标，它就从上面滑下来。

截完就在绳上

微信 Alt+A、QQ 截图、Win+PrtScn——截完那一瞬间，图已经挂上去了。不用找文件，不用切窗口。

推一下鼠标就到

指针碰到屏幕最上沿，绳子滑下来；手一离开，1.8 秒自动收回。桌面干净得像没装过它。

想让它常驻也行

点绳子右端的图钉，或托盘右键勾上「固定在桌面」，它就一直在那儿，重启也还记得。

单击复制、双击打开，拖进微信/邮件就直接发出去 文件直接拖到绳上就挂；资源管理器右键「挂到晾衣绳」支持 27 种格式 全程本地运行：不联网、无账号、无广告、不收集任何数据
